نسخه باشگاه‌ها — روش قرار دادن روی GitHub Pages
==============================================

این پوشه چهار بخش دارد:
  index.html     صفحه شروع (پیوند به برنامه‌ها و راهنما)
  coach-web/     برنامه مربی
  player-web/    برنامه بازیکن
  guide/         راهنمای مصور (صفحه وب)

پیشنهاد: یک مخزن جدا بسازید تا نسخه تیم خودتان دست‌نخورده بماند.
1) github.com ← New repository ← نام: darts (یا هر نام دیگر) ← Public ← Create.
2) Add file ← Upload files ← هر چهار مورد بالا را با هم بکشید و رها کنید ← Commit.
   (پوشه guide حدود ۵ مگابایت تصویر دارد؛ اگر یک‌جا آپلود نشد، پوشه‌ها را جدا جدا آپلود کنید.)
3) Settings ← Pages ← Deploy from a branch ← main / (root) ← Save.
4) بعد از یکی دو دقیقه:
   صفحه شروع:  https://<نام-کاربری>.github.io/darts/
   راهنما:      https://<نام-کاربری>.github.io/darts/guide/

همین یک آدرس را به همه باشگاه‌ها بدهید. داده‌های هر مربی فقط روی دستگاه خودش است
و باشگاه‌ها داده یکدیگر را نمی‌بینند.

در این نسخه:
- هیچ بازیکن، نام تیم یا برنامه تمرینی از پیش وجود ندارد.
- آدرس برنامه بازیکن خودکار شناخته می‌شود و لازم نیست مربی آن را وارد کند.
- پایین برنامه مربی پیوند «راهنمای برنامه» هست.
- قفل یا لایسنس ندارد: هر کسی آدرس را داشته باشد می‌تواند استفاده کند.

به‌روزرسانی: فایل‌های جدید را روی همان پوشه‌ها آپلود کنید؛ داده‌های کاربران پاک نمی‌شود.
